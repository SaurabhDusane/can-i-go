# Can I Go?

A Cubbie Skill for the Cubbie Hackathon (Track 1).

Send Cubbie a screenshot of the party invite and ask "can I go?". It checks what's due, plans the work around your plans, calls you when a work block starts, and sends a Party Pass when you've earned the night. It also spots new Canvas assignments the day they appear and learns your real pace per course.

Install: text this folder's link to Cubbie:
https://github.com/<your-username>/can-i-go/tree/main/can-i-go

Uses only Cubbie's built-in abilities (Canvas, Google Calendar, web, memory, reminders, phone calls, documents). No keys, no scripts.
